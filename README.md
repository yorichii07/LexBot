# LexBot - Legal Assistant Chatbot

LexBot is an intelligent legal assistant chatbot designed to provide quick and accessible information about various laws and regulations. It's a user-friendly web application that helps users find relevant legal information across multiple categories.

## 📋 Features

- **Interactive Chatbot**: AI-powered chat interface for asking legal questions
- **Law Database**: Comprehensive database of Indian laws and regulations
- **Multiple Categories**: Browse laws organized by category (Traffic Laws, Criminal Code, Civil Rights, etc.)
- **Responsive Design**: Mobile-friendly interface with floating navigation
- **Search Functionality**: Quickly find relevant laws and legal information
- **User-Friendly Interface**: Clean, intuitive design with smooth navigation

## 📁 Project Structure

```
lexbot/
```

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or installation required

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yorichii07/LexBot.git
cd LexBot
```

2. Open the application:
   - Simply open `home.html` or `index.html` in your web browser
   - Or use a local server (recommended for better performance)

### Using a Local Server (Optional)

For Python 3.x:
```bash
python -m http.server 8000
```

Then navigate to `http://localhost:8000` in your browser.

## 💻 Usage

1. **Home Page**: Start at the home page for an overview of LexBot
2. **Chatbot**: Click on "Chat Bot" to interact with the legal assistant
3. **Categories**: Browse laws by category through the "Categories" page
4. **Navigation**: Use the top navigation bar or floating navigation ball for easy access

## 📚 Features Overview

### Chatbot Interface
- Ask legal questions in natural language
- Receive relevant law information from the database
- Browse through multiple legal sections and subsections

### Law Database
The `lawdata.json` file contains comprehensive information about:
- Traffic Laws (Speed Limits, Parking, Driving Rules)
- Criminal Laws
- Civil Rights
- Property Laws
- And more...

Each law entry includes:
- Law name and reference
- Detailed description
- Key provisions
- Penalties and enforcement details
